## Motorgeräusche

Alle Motorgeräusche sind echte Aufnahmen von Wikimedia Commons (CC BY 3.0), je Motorbauart eine Gruppe:
Turbo-Vierzylinder „Mitsubishi Lancer Evolution VI“ von *prone* (10 Autos), Sauger-Vierzylinder „Morris Mini“ von *Luciano's Classics*
(Mini/Fulvia/Alpine), Fünfzylinder „Audi RS3“ von *Jay Chesterman* (Quattro S1), Boxer-Vierzylinder „Subaru Impreza STI“ von
*Great Explorer* (Impreza), Boxer-Sechszylinder „Porsche 911 GT3 RS“ von *Supercars67* (959) und V6 „Alfa Romeo GTV6“ von
*Doppia Frizione* (Stratos) – jeweils „… – engine and exhaust sound“, geschnitten, zu Loops verlängert und in der Tonhöhe angepasst
(`tools/make_engine_real.py`, Hörproben `tools/engine_demo.py`). Das Spiel blendet je nach Drehzahl zwischen acht Stufen über.
Details und Links: `engine/QUELLEN.md`, `docs/Motorgeräusche.md`.
